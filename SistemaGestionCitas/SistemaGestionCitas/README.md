# Sistema de Gestión de Citas

## Descripción
Aplicación de escritorio desarrollada en C# con Windows Forms orientada a resolver la gestión, agendamiento y control de citas, clientes y servicios[span_1](start_span)[span_1](end_span).

## Objetivo
Facilitar la administración de citas y el registro de clientes/servicios mediante una interfaz interactiva y el almacenamiento de datos en memoria[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span).

## Funcionalidades Iniciales
- Navegación mediante barra de menú principal.
- Formulario de registro de clientes y servicios.
- Formulario de agendamiento y consulta de citas.
- Validación de campos obligatorios y formato de datos.
- Confirmación de salida e interactividad.
